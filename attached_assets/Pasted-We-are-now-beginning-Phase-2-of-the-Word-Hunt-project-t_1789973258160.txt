3. REWARD GENERATION
====================

When the player successfully completes a Word Hunt level, the Mystery Dumpling system should generate one reward.

The reward-generation logic must be separate from the visual animation.

IMPORTANT:

Generate the reward BEFORE beginning the unboxing animation.

Persist the generated reward before the animation/reveal begins.

This prevents the result from changing if the app is closed during the animation.

The animation should reveal the already-determined reward rather than deciding the reward during the animation.

Design the reward system so that duplicate handling can be controlled later without rewriting the architecture.

For the initial implementation, define a clear deterministic data model for:

* reward ID
* dumpling ID
* rarity
* timestamp/earned state
* collection state

Do not invent complicated economy mechanics yet.

==================================================
