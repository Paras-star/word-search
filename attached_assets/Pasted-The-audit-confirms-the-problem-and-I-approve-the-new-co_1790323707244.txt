## 5. DAILY-TO-DAILY REPETITION

This is extremely important.

Different Daily dates should use different target words.

For example:

September 25:
WORD A
WORD B
...
WORD I

September 26:
different words

September 27:
different words again

The goal is:

* 0 overlap between nearby Daily sets whenever possible
* 1 repeated word occasionally is acceptable
* never intentionally repeat several words
* never intentionally repeat an entire 9-word set within the recent rolling window

With ~400+ words, prioritize disjoint sets for nearby dates.

Do NOT simply shuffle the same 9-word sets.

## 6. DATE DETERMINISM

Keep Daily Puzzle determinism.

For a given date:

`YYYY-MM-DD → deterministic Daily word set + deterministic puzzle seed`

Therefore:

September 25, 2026 must always produce the same Daily Puzzle.

September 26, 2026 produces a different deterministic puzzle.

Closing/reopening the app must not change the puzzle.

Do not use Date.now() for Daily puzzle selection.
