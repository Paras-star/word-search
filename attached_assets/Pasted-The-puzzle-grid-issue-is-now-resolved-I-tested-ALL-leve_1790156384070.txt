--------------------------------------------------
PART 1 — FIX DUMPLING REWARD REPETITION
--------------------------------------------------

I tested the game through multiple levels and noticed that I am getting too many duplicate dumplings.

I am repeatedly receiving the same Common and Uncommon dumplings while other Common/Uncommon dumplings remain uncollected.

This makes the collection system feel unrewarding because the player does not feel like they are discovering new items.

I want to change the reward selection system so that:

COMMON:
- Common dumplings can appear frequently.
- But the system should strongly prefer Common dumplings that the player has NOT collected yet.
- Do NOT repeatedly give the same Common dumpling while several other Common dumplings remain uncollected.
- Ideally, cycle through the available Common collection before allowing repeated Common rewards.

UNCOMMON:
- Same principle.
- Uncommon can appear frequently.
- Prefer uncollected Uncommon dumplings.
- Do not repeatedly give the same Uncommon dumpling while other Uncommon dumplings remain uncollected.

RARE:
- Rare should remain less frequent than Common/Uncommon.
- But when a Rare reward occurs, strongly prefer an uncollected Rare dumpling.

EPIC:
- Epic should remain appropriately rare.
- Epic can become more likely on harder levels and timeout-related reward situations, according to the existing reward design.
- When an Epic reward occurs, prefer an uncollected Epic dumpling.

LEGENDARY:
- Legendary should remain genuinely rare.
- I am completely fine with Legendary being much harder to obtain.
- HOWEVER, an uncollected Legendary must actually be accessible.
- The player should eventually have a realistic path to collecting the Legendary dumplings rather than the RNG effectively locking them away forever.
- Once one Legendary is collected, do not keep rewarding that same Legendary while the other Legendary remains uncollected.
- There are only 2 Legendary dumplings, so both should eventually be obtainable.

IMPORTANT:

Do NOT simply increase the probability of Common/Uncommon/Rare.

The problem is not only rarity probability.

The problem is DUPLICATE SELECTION WITHIN THE SAME RARITY.

For example:

If Common has 12 dumplings and the player owns:

Common #1
Common #2
Common #3

and a Common reward is selected, the system should heavily prefer:

Common #4–#12

rather than repeatedly selecting #1, #2, or #3.

Use an appropriate weighted/uncollected-pool system.

A good general principle is:

UNCOLLECTED DUMPLINGS = HIGH PRIORITY
COLLECTED DUMPLINGS = LOW PRIORITY

And where practical, use a no-repeat pool so that the player sees different dumplings before the system begins repeating them.

Do NOT break the existing rarity distribution just to achieve this.

First inspect the existing rarity/reward logic and preserve its intended rarity behavior.
