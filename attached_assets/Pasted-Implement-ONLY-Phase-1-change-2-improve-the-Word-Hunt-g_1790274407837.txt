Implement ONLY Phase 1 change #2: improve the Word Hunt grid's readability and touch comfort.

Current implementation:

* `app/game.tsx` renders the grid.
* The board is square with `maxWidth: 365`.
* The screen currently has 20pt horizontal padding.
* The grid has a 1pt outer border and 3pt inner padding.
* Cells divide the board equally.
* Letters are currently 15pt bold.
* 10x10 and 12x12 grids are both used.
* Touch coordinates are mapped from the measured inner grid content using the existing measurement system.

Goal:
Make the letters/cells slightly easier on the eyes and slightly more comfortable to touch, without breaking the existing responsive layout or touch accuracy.

   * On shorter/narrower phones, the board must shrink rather than overflow.

   * Do NOT introduce a separate visual cell size and touch cell size.
   * Do NOT hard-code touch coordinates.
   * Keep `measureInWindow` / `refreshGridBounds` / existing coordinate mapping intact.
   * Touching the center and edges of cells must still select the correct cell.

4. Handle both 10x10 and 12x12 grids.

   * 12x12 is the important readability case because its cells are smaller.
   * Check that letters remain centered and don't overlap borders.
   * Check that adjacent letters remain visually distinguishable.

5. Keep the visual style consistent with the current game.

   * Do not redesign the board.
   * Do not change colors, selection effects, word list, scoring, hints, or animations.
